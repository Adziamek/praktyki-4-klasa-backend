# WMS-Backend
Warehouse Managment System - Backend [Praktyki 2026]<br>
Spełnione zostały wymagania z pierwszego etapu:<br>
• ASP.NET Core / .NET 10<br>
• PostgreSQL jako baza danych<br>
• Entity Framework Core do obsługi dostępu do danych i migracji<br>
• GitHub jako repozytorium kodu<br>
• GitHub Actions jako podstawowy mechanizm CI<br>
• Swagger lub Scalar do dokumentowania i testowania API,<br>
• pracę z repozytorium zgodnie z podejściem GitFlow.<br>
• Clean Architecure<br>
• Połączenie z Front-Endem
